Search syntax guide

The default: plain words. Type words like you would in any search box: flask sqlite tagging. Every word must appear somewhere in the result, but not necessarily together or in order. Punctuation is safe — don't, B.Sc., and covid-19 all work as-is.

"Exact phrase" — words together, in order. Wrap words in double quotes to match them as a unit. "branch point" finds only places where those two words sit side by side; without quotes, they could be paragraphs apart.
Example: "upload history" — matches the phrase, not scattered mentions of uploads and history.

prefix* — match the start of a word. Put an asterisk at the end of a word stem to match every word beginning with it.
Example: electr* matches electric, electrical, electronics, electron.
The asterisk only works at the end of a word — *lectric won't.

NEAR(a b, N) — words close together, any order. Matches when the terms appear within N words of each other, in either order. Useful when you remember the concept but not the phrasing.
Example: NEAR(memory project, 8) matches "project memory," "memory for this project," and similar.
If you leave off the number — NEAR(memory project) — the distance defaults to 10.

AND, OR, NOT — combining and excluding. These must be uppercase; lowercase and/or/not are treated as ordinary search words.

  • flask AND sqlite — both must appear. (This is already the default between plain words.)
  • flask OR fastapi — either one is enough.
  • python NOT snake — has python, doesn't have snake. NOT sits between two terms. There is no leading-minus exclusion — -snake is treated as an ordinary word, which is why searches like covid-19 keep working.

( … ) — grouping. Parentheses make combinations unambiguous.
Example: (flask OR fastapi) AND sqlite — sqlite, plus at least one of the two frameworks.

Mixing operators with ordinary words. The moment a query contains any operator, the whole query switches to strict syntax mode — punctuation is no longer handled for you. Quote anything with apostrophes, periods, or hyphens:
"B.Sc." AND engineering works; B.Sc. AND engineering is a syntax error.

Putting it together. ("export viewer" OR archive) NOT readme — finds export-viewer or archive content while skipping anything that mentions readme. When combining different operators, use parentheses rather than relying on precedence rules.

What's searched: conversation titles and summaries, every message (including messages on alternate branches), project names and descriptions, knowledge documents, and all memory — the conversation memory, memory files, and project memories.

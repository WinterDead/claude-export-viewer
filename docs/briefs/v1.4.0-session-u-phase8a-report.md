## F1 — the app's pages reach no network (amendment A9)

Every response the app serves gets this header from an `after_request` hook in `app.py`
(`setdefault`, so the artifact-file route keeps its stricter policy):

```
default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self' data:;
font-src 'self'; connect-src 'self'; frame-src 'self'; media-src 'none';
worker-src 'none'; manifest-src 'none'; object-src 'none'; base-uri 'none';
form-action 'self'; frame-ancestors 'self'
```

- **Inline styles: none needed.** The templates carry no `style` attribute or `<style>`
  element (test-pinned), so `style-src` is `'self'` with no `'unsafe-inline'`.
- **Inline script: five inline event handlers found and moved** to
  `static/page_controls.js` — the Theme select, the conversations tag filter, the per-row
  tag dropdown, Hide legacy memory (`data-autosubmit`), and the project-memory title link
  inside its summary (`data-stop-propagation`). The templates now carry no inline handler
  and no inline `<script>` (test-pinned).
- `connect-src 'self'` is Copy conversation's fetch of the export; `frame-src 'self'` is
  the artifact preview; `img-src data:` admits no remote origin.
- No sanitiser-allowlist change: the fixture's remote Markdown image
  (`https://images.example.invalid/pixel.png`, added to the current-format conv-2 reply)
  still renders as an `<img>`, and the browser refuses it.
- Help gains E1.

## F2 — export-sourced URLs (the path list)

`viewer.render.web_url` decides every export-sourced `href`. A grep of the templates for
`href="{{` not built by `url_for` found:

| Path | Before | Now |
|---|---|---|
| `templates/_message.html` — `rich_link` `link.url` | raw | `web_url`; text with no anchor otherwise |
| `templates/_message.html` — citation `details.url` (Sources list) | raw | `web_url`; text with no anchor otherwise |
| `templates/manifest.html` — `export_url` (via `routes._https_url`) | https check of its own | `web_url`, narrowed to https |
| `templates/search.html` — message hit link | built from `url_for` | unchanged (not export-sourced) |

Markdown links remain governed by the sanitiser's protocol list, unchanged. `web_url`
drops tabs, newlines, and carriage returns anywhere, trims leading and trailing spaces and
control characters (as browsers do), and accepts only `http`/`https` with a host. Tested:
`javascript:` in mixed case, with leading whitespace, leading control characters, and an
embedded tab, newline, or carriage return; `data:`; `vbscript:`; protocol-relative
`//host`; `https://` with no host; `ftp:`; `mailto:`; empty and non-string values. Both
template sinks are tested through the rendered partial.

## F3 — partial sets never orphan tags (amendment A11)

`TagState` gains `held_conv` / `held_project` and the two paused flags. With no
conversations category, rows whose conversation is absent are held; with no projects
category, rows whose project is absent are held. Held rows are neither counted nor
purgeable; the banner and `/orphans` show E2. Tested through the rendered pages and the
purge route: no conversations, no projects, neither (a `frames`-only upload), and a full
set (a genuinely gone conversation is still counted and purged). Inspect is untouched
(orphan state always reads the primary export).

## F4 — no cross-origin header (amendment A10)

is replaced by `test_no_artifact_file_response_carries_a_cross_origin_header`, which
checks every servable fixture file for any `Access-Control-*` header. Help gains E3.

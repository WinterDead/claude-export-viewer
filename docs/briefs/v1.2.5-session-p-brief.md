## Gate vocabulary

- **Soft gate** — resolve it if the fix is obvious and within the design's intent, and flag
  it prominently in the report.
- **Hard stop** — end the phase and report without implementing, even if the resolution
  seems obvious.

**Hard stops**: the designed Phase 1 → Phase 2 boundary (mandatory, nothing committed
before operator review); any sanitiser or stack change; any user-facing copy beyond the
verbatim pieces below; any claim in edited docs that fails verification.

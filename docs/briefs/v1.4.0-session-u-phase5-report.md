## Disclosures (four-part)

**G5.1 — the Artifacts page without `frames`.** *Observation*: record §10 says data without
`frames` is "listed as orphans", but the nav entry shows only with `frames`. *Decision*: the
nav follows §6.2; the page answers at its URL when the set has `frames` **or** artifact data
(404 when neither), so orphans stay reachable.

**G5.2 — Scheduled tasks nav position.** *Letter*: only Artifacts' position is given.
*Decision*: directly after Artifacts.

**G5.3 — fonts and CORS (security-relevant; flagged for review).** *Observation*: the
preview has an opaque origin, and browsers fetch web fonts in CORS mode, so a relative
font can't load without an `Access-Control-Allow-Origin` header. *Letter*: outcome 4 —
"relative assets (CSS, fonts, images) load from the export". *Intent*: fonts render
without opening the files to other sites. *Decision*: font responses (only) carry
`Access-Control-Allow-Origin: null` and no credentials header. Residual exposure: a page
that already knows an artifact's id and version id could read that font file from a
sandboxed frame of its own; no other file type is readable cross-origin. If the operator
prefers no CORS header at all, outcome 4 holds for CSS and images but not fonts.

**G5.4 — View source's form.** *Letter*: "View source (the entry HTML through the existing
highlighter, collapsed by A5's rule)". *Decision*: under A5's thresholds the source renders
open under a `View source` heading; over them, a collapsed `View source ({N} lines)`
(U1's count pattern). Inline on the detail page, per record §10's View-source line.

**G5.5 — headers beyond the record.** *Decision*: the file responses also carry
`frame-ancestors 'self'` (only this viewer may frame them), `Referrer-Policy: no-referrer`,
and `Cache-Control: no-store`; the iframe sets `referrerpolicy="no-referrer"`.

**G5.6 — Run history layout.** *Letter*: run headers have no task column. *Decision*: runs
are grouped under each task's name (and orphan runs under their routine id), so every
table stays within the D9 headers.

**G5.7 — search section headings.** *Decision*: the page headings, `Published artifacts`
and `Scheduled tasks` — no new copy.

**G5.8 — smaller calls.** Prompts render through the Markdown pipeline (no allowlist
change); `Size` reads `{n} bytes` like attachments; download names are the slugified title
plus the version id.

# v1.1 Session B — "No Project" sentinel: verification matrix

All tests live in `tests/test_no_project.py` unless noted. The sentinel value is
`viewer.tagging.NO_PROJECT_SENTINEL` (`__no_project__`), display label "No Project",
URL slug `no-project`.

## Verification matrix

| Surface | Behaviour with sentinel | Test covering it |
| --- | --- | --- |
| Per-row dropdown (conversations list) | "No Project" is the first project option, ahead of real projects, distinct from "(Untagged)"; selecting it tags the row | `test_tag_to_no_project_via_conversations_list_dropdown`, `test_no_project_listed_first_ahead_of_real_projects` |
| Conversation-detail dropdown | Same option set; sentinel selected after tagging; never rendered with the `(Orphan: …)` treatment | `test_tag_to_no_project_via_detail_page_dropdown` |
| Untag vs sentinel | Clearing a sentinel row returns the conversation to Untagged (not-yet-reviewed) — a different action from tagging to No Project | `test_untag_returns_no_project_row_to_untagged` |
| Bulk bar — "Tag selected" | Sentinel is a valid target; existing skip-already-tagged rule unchanged (sentinel rows count as tagged) | `test_bulk_tag_selection_to_no_project`, `test_bulk_tag_mode_skips_rows_already_marked_no_project`, `test_bulk_picker_offers_no_project` |
| Bulk bar — "Retag all selected" | Sentinel is a valid overwrite target | `test_bulk_retag_tagged_rows_to_no_project` |
| Bulk bar — "Untag selected" | Clears sentinel rows like any tag | `test_bulk_untag_clears_no_project_rows` |
| Conversations-list filter | `?tag=no-project` shows only sentinel-tagged rows; `?tag=untagged` excludes them; real-project filters exclude them; dedicated empty-state copy | `test_filter_no_project_shows_only_sentinel_rows`, `test_filter_untagged_excludes_sentinel_rows`, `test_filter_real_project_excludes_sentinel_rows`, `test_filter_select_offers_no_project_slug`, `test_filter_no_project_empty_state` |
| `/projects` | Never lists the sentinel (value or label) | `test_projects_page_never_lists_sentinel` |
| Home-page stats | Project count derived from the export — unchanged by sentinel rows | `test_home_project_count_unchanged_by_sentinel_rows` |
| TagState buckets | Sentinel on a live conversation → bucket `live`; never orphan-project | `test_sentinel_on_live_conversation_is_bucket_live` |
| `/orphans` — orphan-conversation bucket | Sentinel row whose conversation is missing lands here, rendered with the "No Project" label and **no** "project also missing" badge | `test_sentinel_on_missing_conversation_is_orphan_conv`, `test_orphan_conv_sentinel_row_has_no_missing_project_badge` |
| `/orphans` — orphan-project bucket / banner | Sentinel rows on live conversations produce no orphans of either kind, so no banner | `test_no_orphan_banner_for_live_sentinel_rows` |
| Orphan purge | Clears sentinel orphan-conversation rows like any orphan; never touches live sentinel rows | `test_purge_clears_sentinel_orphan_conv_but_not_live_sentinel`, `test_purge_route_clears_sentinel_orphan_conv_row` |
| Sentinel project-detail URL | `/projects/__no_project__` redirects (302) to `/conversations?tag=no-project` rather than 404ing | `test_sentinel_project_detail_url_redirects_to_filtered_list` |
| Persistence | Sentinel tag survives a re-import through the upload flow and still resolves as live | `test_sentinel_tag_survives_reimport` |

## Browser-pass list (manual review)

Performed read-only against a live archive after the change (dropdown contents,
filter, `/projects` absence, redirect — all confirmed); the tagging writes below
are worth one manual pass in the browser:

1. On `/conversations`, tag a conversation to No Project from the per-row
   dropdown; confirm the dropdown re-renders with "No Project" selected.
2. Open a conversation and tag it to No Project from the detail-page dropdown;
   confirm the same, then untag it and confirm it returns to Untagged.
3. Use the Filter select to switch to "No Project"; confirm only
   sentinel-tagged conversations are listed and the URL reads
   `?tag=no-project`.
4. Select a mixed set of rows (some untagged, some tagged), pick "No Project"
   in the bulk bar; confirm "Tag selected" skips the already-tagged rows and
   "Retag all (overwrite)" converts them.
5. Visit `/projects` and confirm No Project does not appear as a project.

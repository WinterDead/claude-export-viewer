## What shipped

1. **Conftest consolidation.** `tests/conftest.py` now carries the suite's shared
   fixtures: `export_path` (the container-format parametrisation seam — defaults to the
   legacy happy-path ZIP, indirectly parametrisable to any fixture container, including a
   current-format set directory), `export` (parsed model), `app`, `client`, `app_factory`
   (monkeypatch-based, Session K cache-directory layout), the `SYNTHETIC_EXPORT` constant,
   and one CSRF scraper (`scrape_csrf`). All 46 `"synthetic_export.zip"` code literals
   across 21 files now route through the shared fixtures/constant; the ~12 byte-identical
   `client` fixtures, the three `app_factory` copies plus one inline, and the eight
   scraper definitions plus three inline copies are gone.
2. **Monkeypatch fixes.** The direct module-global rebinding in `tests/test_export.py`,
   `tests/test_inspect.py`, and `tests/test_no_project.py` (and, absorbed by the dedup,
   `tests/test_upload.py`) now goes through the shared `app_factory`'s
   `monkeypatch.setattr`, matching `test_history.py`/`test_startup.py`.
3. **Regeneration guard.** `tests/test_fixtures.py` rebuilds every fixture via
   `build_fixtures.build_all(tmp_path)` and byte-compares against the checked-in
   binaries — in both directions (builder output without a checked-in twin fails; a
   committed binary without a builder fails).
4. **Asset-matrix hole.** `/inspect` added to `test_highlighting.py`'s `ALL_PAGES`
   (matrix now matches `test_help.py`'s).
5. **Current-format fixture set.** `build_fixtures.py`'s registry extended with
   `FIXTURE_SETS` — entries that emit multiple outputs into a directory — producing three
   byte-stable sets, all covered by the regeneration guard:
   - `current/`: a realistic-named manifest (with `example.invalid` export URLs) plus the
     four category zips. Conversations carry all five block types including the
     injected-prompt trio (`prompt`, `initial_turn_only`,
     `skip_on_truncated_continuation`); thinking with summaries, without summaries, and
     with `thinking_hidden` true; a `signature` sentinel value; text-block citations
     (two, with offsets into the raw text, plus `citations_grouping_mode`); all six
     `display_content` types (`text`, `table`, `rich_link`, `json_block`, `rich_content`,
     `code_block`); knowledge `links`; and `meta.output_format_category: md`. The
     memories zip is the current dict shape with `memory_files` covering a `/people/`
     path, a two-level-deep path, and one file without frontmatter. `light_metadata`
     holds `users.json` plus `login_history.json` with three events, RFC 5737 IPs only,
     deliberately unordered so newest-first sorting is testable.
   - `current_two_part/`: a two-part conversations category whose part 1 carries a
     mutated duplicate of conv-1 (same UUID, different name) for the multi-part-merge
     preserve-and-flag test.
   - `current_dangling/`: a swap-in memories zip with a dangling project memory — the
     current-format twin of `bad_dangling_memory.zip`.
6. **Checklist step 7 rider.** The plan's export-ignore bullet reworded from "Dev docs"
   to "Development briefs" (ratified scope), and the stray empty comment line removed
   from `.gitattributes`.

Suite at close: **473 passed** (470 baseline + 1 new `/inspect` asset-matrix case + 2
regeneration-guard tests), ruff clean, black clean.

## Disclosed judgment calls

- **Shared `app_factory` database location.** The Session K pattern won: `viewer.sqlite`
  lives under `tmp_path/cache/` so one snapshot covers all writable state.
  `test_history.py`'s row-reading call sites were updated to the new path; its behaviour
  is unchanged.
- **Scraper page defaults.** `scrape_csrf` defaults to `/upload`; the inspect and export
  suites pass `/inspect` explicitly because those tests scrape mid-inspection, when the
  upload form is in its disabled state.
- **Fixture naming.** The duplicated `synthetic_client`/`synthetic_export` names retired
  in favour of the shared `client`/`export`; `test_help.py` and `test_highlighting.py`
  keep module-level `client` overrides (their exports pin `source_paths` to a bare
  filename for the verify-negative checks), and `test_export.py` keeps its override that
  appends the exotic conversations.
- **Behavioural parity of the current set.** The current-format conversations reuse the
  legacy builders' records — same UUIDs, same message counts — with the new-format
  features added as extra blocks inside existing messages, so count-level test
  expectations hold across both containers when Phase 2 parametrises the suite. This is
  also why the dangling memory and the two-part category live in separate set
  directories: a whole-directory load of `current/` is exactly the canonical happy set.
- **Signature sentinel.** The fixture's `signature` value is the distinctive constant
  `SIGNATURE_SENTINEL` (exported by `build_fixtures.py`) so Phase 2's deliberate-drop
  test can assert those bytes reach neither the model nor the parse cache.
- **`.gitattributes` additions beyond the rider.** The three new set directories are
  pinned `-text` — the manifest is JSON, and EOL conversion on a Windows checkout would
  break the byte-compare the regeneration guard performs. `build_all` gained a
  `target_dir` parameter for the same reason (the guard builds into a temp directory
  rather than overwriting checked-in files).
- **Guard direction.** The regeneration guard also asserts the reverse direction (no
  unregistered `.zip`/`.json` under `tests/fixtures/`), which the brief did not require
  but which the same rebuild makes free.

The (c)-ranked coverage gaps from the Session R review (sort options, project-detail
content, home stats) remain queued, per the brief — not absorbed.

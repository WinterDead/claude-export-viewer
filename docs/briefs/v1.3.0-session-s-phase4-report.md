## Disclosed judgment calls

- **"Rendered as text" (§7, conversation memory).** Read as "the blob, no structural
  parsing" rather than "strip its formatting": the existing collapsible
  Markdown-with-sections rendering is kept, retitled. Regressing the blob to plain
  text would have destroyed the section anchors search links depend on, and C7 names
  the heading, not a rendering change. The anchor id stays `global-memory` (internal,
  not copy) so existing search links and the home-page block still resolve.
- **Group headings on one page.** The three C7 headings are `<h2>` groups; the sort
  toggle moved inside the Project memories group (it only ever sorted those); the
  orphan section became an `<h3>` within it. The page's empty state and all existing
  behaviours (collapsed-by-default, section toggles) are unchanged and still
  test-pinned.
- **Memory page stays reachable without a memories category** — it shows its empty
  state rather than 404ing; the C1 banner names the reason. The record hides only the
  Account nav entry.
- **Memory-file ordering.** Groups alphabetically with root files first; files by path
  within a group. The record specifies grouping but not order.
- **Thinking teaser.** When summaries exist the collapsed line is the first summary
  (with the existing truncated/cut-off markers appended); without summaries the
  `Thinking (N chars)` teaser stays. The record's letter — the teaser *is* the first
  summary — was followed rather than prefixing a "Thinking" label.
- **`display_content` vs `md`.** When a result carries both, `display_content` wins
  (it is "the tool card's body" per §9.5); `output_format_category: md` applies to
  results without one. Inner text of ordinary results remains summarised, not
  rendered.
- **Account cell condensation.** Browser & OS: `{browser} {version} · {os} {version}`
  with absent parts dropped; Location: non-null of city/region/country joined with
  commas; `—` for fully empty cells. C4 fixes the headers; the cell format is
  implementation-drafted.
- **Account nav position** — after Memory, with the data pages, ahead of the
  Search/Upload/History/Inspect/Help tail whose order is a Session O operator
  decision.
- **`User.verified_phone_number`** added to the model (§8 says "the identity fields
  from `users.json`"; the model previously dropped the fourth field). Parser-hash
  cache invalidation covers the change.
- **`json_block` fallback shows the payload string as-is** (it is already a JSON
  document); `rich_content` and unknown display types pretty-print via the new
  `pretty_json` filter. The type set is treated as open (§9.5's fallback covers
  unknown values).
- **No browser pass this session** — the rendering work is HTML-pinned by tests, and
  the visual walk belongs to the operator hand-test brief (a file picker cannot be
  driven programmatically, and the dev server would load the real export).

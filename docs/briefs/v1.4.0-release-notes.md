## v1.4.0 — current exports, published artifacts, and scheduled tasks

- Current exports load again: files this version doesn't recognise are skipped with a
notice instead of stopping the upload.
- New Artifacts page: every published artifact with its versions, a safe preview (no
scripts, nothing loaded from the web), its files, comments, and saved data.
- Conversations link to the artifacts they published.
- New Scheduled tasks page for Claude Code scheduled tasks and their run history.
- Artifacts and scheduled tasks are searchable.
- New Download links page turns your manifest into one-click downloads.
- The old memory summary is marked as no longer updated when your export has memory
files, and can be hidden.
- Attached documents in conversations show by name; single-ZIP exports show their login
history when they include it.
- Large tool results start collapsed with a line count.
- Security: links that come from an export open only web addresses, and the viewer's
pages can no longer load anything from the web — including images in messages.
- Uploading only some of your export files no longer marks your tags as orphans.
- For developers: the real-data test hook takes an external path
(VIEWER_REAL_EXPORT_DIR) and the data/ fallback is retired; launcher messages are clearer
on Linux, macOS, and Windows with several Pythons installed.

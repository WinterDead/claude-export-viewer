# v1.3.0 — current export format, memory files, dark mode

Anthropic changed the data-export format: exports now arrive as a manifest plus
separate ZIP files for conversations, projects, memories, and account metadata, and the
memory system moved to a file-based model. This release loads both that format and the
older single-ZIP exports.

- Upload the new export files together — any subset loads, and a banner names what's
missing. Older single-ZIP exports load exactly as before.
- Memory page: conversation memory, memory files grouped by folder with their metadata
headers, and project memories.
- New Account page: your account details and login history.
- Richer conversation rendering for current exports: tool cards use the app's display
content, cited sources are listed beneath paragraphs, thinking blocks are teased by their
summaries, and injected prompts appear as collapsible cards.
- Dark mode, following your system preference with a manual override.
- The 200 MB upload cap is now per file and configurable (VIEWER_MAX_UPLOAD_MB).
- Thinking-block verification signatures are not stored or displayed — see the help
page's "What the viewer doesn't keep".
- New developer tool: tools/scan_export_schema.py, an aggregate-only schema profiler
for either export format.

Full details in docs/format-support-design.md and docs/export-schema.md.

## Phase 8a — fixes (each with tests; record amendments applied verbatim)

### F1 — the app's own pages reach no network (amendment A9)

Every page and response the app serves, other than the artifact-file routes (which keep
their stricter policy), carries a Content Security Policy (CSP) with these outcomes:

- no remote origin is permitted for any fetch directive (images, styles, fonts, scripts,
  media, frames, connections);
- no inline script and no `eval`; therefore `javascript:` URLs cannot execute;
- `object-src 'none'`, `base-uri 'none'`, `form-action 'self'`, `frame-ancestors 'self'`;
- inline styles only if the templates genuinely need them — verify, prefer none, and
  disclose the finding either way.

No sanitiser-allowlist change: remote images survive sanitising as before, and the browser
refuses to fetch them. Tests: the header on every route in the route table (generated
list, so new routes are covered automatically); a remote Markdown image in a fixture
message; a verify-negative that no CSP permits a remote origin. **Driven-browser pass**
over every page of the synthetic fixture, in both themes: zero CSP violations in the
console (any violation means a page broke — fix the page, not the policy), and the remote
image request never leaves the browser (network log). Help gains E1.

### F2 — export-sourced URLs are links only when they are web addresses

One helper decides, for every URL that comes from an export and renders as an `href`
(`rich_link`, citations, and any other path a grep of the templates finds — list them all
in the report): `http` and `https` render as links; anything else renders as plain text
with no anchor. Tests cover `javascript:`, `data:`, `vbscript:`, mixed case, leading
whitespace and control characters, embedded tabs and newlines in the scheme, and
protocol-relative `//host`. F1 is the backstop; F2 is the fix.

### F3 — subsets never orphan your tags (amendment A11)

When the primary set lacks the conversations category, conversation-orphan classification
and its purge are suspended; when it lacks projects, project-orphan classification and its
purge are suspended. The orphan banner and `/orphans` show E2 instead, with no purge
control for the suspended dimension. Inspect is unaffected (tags never pair with an
inspected export). Tests: each dimension alone, both, and a full set unchanged — through
the rendered pages and the purge route.

### F4 — no cross-origin header on artifact files (amendment A10)

Remove `Access-Control-Allow-Origin: null` from font responses. No artifact file carries
any cross-origin header. Fonts fall back to system fonts; CSS and images still load.
Replace `test_font_responses_admit_only_opaque_origins` with a verify-negative that no
artifact-file response carries `Access-Control-Allow-Origin`. Help gains E3.

the D3 lines change to E4's forms.
